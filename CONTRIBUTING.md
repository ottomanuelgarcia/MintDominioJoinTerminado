# Contribuir

Gracias por interesarte en este proyecto.

## Cómo contribuir

1. Haz un fork del repositorio.
2. Crea una rama para tus cambios.
3. Realiza tus modificaciones y añade pruebas cuando sea posible.
4. Abre un pull request explicando el cambio.

## Estilo

- Mantén el código claro y bien comentado.
- Evita introducir dependencias innecesarias.
- Si cambias el comportamiento de descubrimiento de dominios, actualiza las pruebas.
